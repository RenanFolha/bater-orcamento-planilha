Por padrão o sistema usa um arquivo SQLite local. Pra apontar pra um servidor SQL Server, MySQL ou PostgreSQL, preencha os dados abaixo, teste a conexão e confirme a migração — todos os dados já cadastrados (filiais, veículos, histórico etc.) são copiados pro banco novo automaticamente, e só depois disso a API passa a usar ele.
